# Stable or beta?

AetherTube ships as **two separate apps**. They have different package names, so they install
side by side, update independently, and neither can overwrite the other.

|  | **Stable** | **Beta** |
| :-- | :-- | :-- |
| Released | when a version is tagged deliberately | automatically, on every change |
| On the releases page | marked **Latest** | marked **Pre-release** |
| Package | `…aethertube.stable` | `…aethertube.beta` |
| Good for | actually watching things | seeing new work early, and finding its bugs |

!!! tip "Recommendation"
    **Take stable unless you want to help test.** Because they're genuinely separate installs, you
    can run both on the same TV — keep stable as the one you actually use, and let beta be the one
    that occasionally breaks. Each channel only ever updates itself: a beta build is never offered
    as an update to a stable install, and vice versa.

## Where to find each

Both are built from the same [Releases page](https://github.com/abhimanbhau/AetherTube/releases):
stable releases are the ones marked **Latest**, beta releases are marked **Pre-release**.
