# Transfer settings

Move your whole setup — video quality, playback behavior, SponsorBlock, interface tweaks — to
another device (or back onto the same one after a wipe/reinstall) with a short code, no account
and no cloud step involved.

## Generate a code on the source device

1. Open **Settings → AetherTube → Transfer settings**.
2. Generate a code. It looks like `3G41-96RJ-ARGN`.
3. Write it down, or keep it visible on screen while you set up the new device.

## Apply it on the destination device

1. Install AetherTube on the new device (see [Installation](installation) if you haven't yet).
2. Open **Settings → AetherTube → Transfer settings** on the new install.
3. Enter the code from the source device.

Your settings are restored immediately — no restart needed.

## Why this instead of a cloud backup?

The code *is* the backup. There's no account to sign into and nothing sent to a server, so
there's nothing to breach. The tradeoff is that you're responsible for keeping the code somewhere
you can find it — it isn't stored anywhere on AetherTube's side.
